¡Bienvenido a IntelliText API!

Potencia tus aplicaciones con análisis de texto impulsado por inteligencia artificial. Extrae insights, clasifica contenido y comprende texto como nunca antes.

Características

🤖

IA Avanzada

Utiliza modelos de lenguaje de última generación para proporcionar análisis precisos y detallados de cualquier texto.

⚡

Rápido y Escalable

Respuestas en milisegundos con capacidad para manejar miles de solicitudes simultáneamente.

🔒

Seguro

Tus datos están protegidos con encriptación de extremo a extremo y nunca se usan para entrenar modelos.

📊

Análisis Profundo

Extrae sentimientos, entidades, categorías y métricas de calidad de cualquier documento o texto.

Documentación de Endpoints

GET / Información de la API
Response 
// Información general de IntelliText API
{
  "name": "IntelliText API",
  "version": "1.0.0",
  "description": "AI-powered text analysis API",
  "endpoints": {
    "health": "/health",
    "analyze": "/analyze"
  }
}
GET /health Health check del servicio
Response 
// Estado del servicio
{
  "status": "ok",
  "uptime": 123.456,
  "timestamp": "2026-02-05T14:30:00.000Z"
}
curl 
curl https://your-api.elasticbeanstalk.com/health
JavaScript (Fetch) 
const response = await fetch('https://your-api.elasticbeanstalk.com/health');
const data = await response.json();
console.log(data);
POST /analyze Análisis principal de texto
Request Body 
// Envía el texto a analizar
{
  "text": "El producto es excelente, muy recomendado"
}
Response 
// Resultado del análisis
{
  "sentiment": "positive",
  "confidence": 0.95,
  "entities": ["producto"],
  "suggestions": ["Excelente"],
  "metrics": {
    "readability": "easy",
    "wordCount": 5
  }
}
curl 
curl -X POST https://your-api.elasticbeanstalk.com/analyze \
  -H "Content-Type: application/json" \
  -d '{"text": "El producto es excelente"}'
JavaScript (Fetch) 
const response = await fetch('https://your-api.elasticbeanstalk.com/analyze', {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify({
    text: 'El producto es excelente'
  })
});
const result = await response.json();
console.log(result);
Python (requests) 
import requests

response = requests.post(
    'https://your-api.elasticbeanstalk.com/analyze',
    json={'text': 'El producto es excelente'}
)
result = response.json()
print(result)
